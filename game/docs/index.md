# sanctuary — composed engine

**Start with [make-a-2d-game.md](make-a-2d-game.md), and read it whole:** the whole surface in one page. The other pages are reference: look a thing up there when the page sends you, or for a pack you added.

This game composes `core-2d`, which brings `render-auto`, `world-screen`, `rig-follow`, `controls-2d`, `maths`, `color`, `audio`, `tween`, `backdrops`, `backdrop-sky`, `backdrop-stars`, `render-texture`, `particle-textures`, `particles-2d`, `feel`, `collision`, `pointer`; and `world-topdown`, `typography`, `ui`, `save`, `ui-skins`, `ui-skin-metal`, `arena-layout`, `nav`, `bars`, `lighting-2d`, `nine-slice`, `dialogue`, `art-2d`, `post`, `post-looks`.
Nothing else exists. Import `game` from `./engine.js`.
